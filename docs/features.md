# Функции Alem (11 модулей)

## 1. Dashboard (Панель управления)

Главный экран с обзором всех активностей.

- Сегодняшние задачи
- Активные смены
- Предстоящие дедлайны
- Напоминания
- Статистика дня
- Быстрый доступ к модулям

## 2. Shifts (Смены)

Отслеживание рабочих расписаний.

- Добавление и редактирование смен
- Календарь смен
- Расчёт отработанных часов
- Статистика заработков
- Экспорт отчётов

## 3. Tasks (Задачи)

Список дел с приоритетами.

- Добавление задач
- Приоритеты (высокий, средний, низкий)
- Сроки выполнения
- Фильтрация по статусу
- Отметка выполнения

## 4. Deadlines (Дедлайны)

Дедлайны по предметам ЕНУ/ВТ-33.

- Дедлайны по предметам
- Напоминания перед дедлайном
- История сданных работ
- Уведомления в системе

## 5. Habits (Привычки)

Трекер привычек со стриками.

- Добавление привычек
- Ежедневная отметка выполнения
- Счётчик текущего стрика
- График прогресса
- Цели по привычкам

## 6. Budget (Бюджет в ₸)

Управление личными финансами в казахстанских тенге.

- Добавление доходов и расходов
- Категории (еда, транспорт, развлечения и т.д.)
- Графики расходов
- Месячный бюджет и планирование
- Статистика по категориям

## 7. Channels (Личные каналы)

Личные каналы как в Telegram.

- Создание каналов
- Отправка сообщений и заметок
- Форматирование текста (TipTap)
- Поиск по каналам
- Синхронизация данных

## 8. Fitness (Фитнес)

Логирование тренировок.

- Типы упражнений
- Длительность тренировки
- Таймер отдыха между подходами
- Статистика тренировок
- График активности

## 9. Notes (Заметки)

Быстрые заметки и идеи.

- Создание и редактирование заметок
- Теги для организации
- Поиск по тексту
- Закрепление важных заметок
- Автосохранение

## 10. Statistics (Статистика)

Аналитика по всем модулям.

- Графики активности
- Прогресс по привычкам
- Расходы по месяцам
- Время, проведённое в приложении
- Экспорт отчётов в PDF

## 11. Settings (Настройки)

Конфигурация приложения.

- Профиль пользователя
- Выбор языка (Русский/Казахский)
- Тема оформления (тёмная/светлая)
- Резервная копия данных
- Удаление данных
- Версия приложения
