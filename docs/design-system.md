# Система дизайна Alem

## 🎨 Палитра цветов

### Основные цвета

| Имя | Код | Использование |
|---|---|---|
| Background | `#0F0F17` | Основной фон приложения |
| Surface | `#16161F` | Карточки, контейнеры |
| Surface2 | `#1E1E2E` | Вложенные элементы |
| Border | `#2A2A3D` | Границы элементов |

### Акцентные цвета

| Имя | Код | Использование |
|---|---|---|
| Accent (фиолетовый) | `#7C6AF7` | Кнопки, выделение |
| Accent2 | `#A78BFA` | Hover состояния |
| Green (успех) | `#4ADE80` | Успешные действия |
| Orange (предупреждение) | `#FB923C` | Предупреждения |
| Red (ошибка) | `#F87171` | Ошибки |
| Blue | `#60A5FA` | Информация |

## 📝 Типографика

- **UI текст**: Inter
- **Монопространство** (время, числа): JetBrains Mono

## 📱 Брейкпоинты

- Mobile: 320px - 640px
- Tablet: 641px - 1024px
- Desktop: 1025px+

## 🌓 Тёмная тема

Все компоненты используют тёмную тему по умолчанию.
